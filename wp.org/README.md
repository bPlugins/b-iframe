# WordPress.org listing assets — iFrame (slug: b-iframe)

Files in this folder are uploaded to the plugin's `assets/` directory on
WordPress.org SVN. They are NOT shipped inside the plugin zip.

## Source artwork

Generated by `build-assets.py` (fonts in `src-fonts/`, dark logo in
`src-logo-dark.svg`):

- `icon.svg` (256×256) — a browser window holding a responsive 16:9 embed
  with markup chevrons and an orange resize handle; subtle CSS loop, frozen
  under `prefers-reduced-motion`, rest frame equals the static exports.
- `banner.svg` (1544×500) — "Embed anything. Fit everywhere."

Edit copy or colours in `build-assets.py` and re-run `python3 build-assets.py`.

## PNG exports wp.org expects

| File | Size |
|------|------|
| `icon-128x128.png` | 128×128 |
| `icon-256x256.png` | 256×256 |
| `banner-772x250.png` | 772×250 |
| `banner-1544x500.png` | 1544×500 |
| `screenshot-N.png` | ~1280×800, numbered to match readme.txt |

Also accepted: `.jpg` for banners/screenshots. Keep every file under 1 MB.
